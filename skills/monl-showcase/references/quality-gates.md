# Showcase quality gates

## Composition

- Provide a complete first screen: identity, purpose, primary action, and useful proof or state.
- Use at least three levels of information hierarchy.
- Give every major entity an appropriate representation: editorial card, product card, schedule, table, queue, detail, or timeline.
- Include enough realistic content to make filtering, empty states, and responsive behavior demonstrable.

## Interaction

- Make every contract route required by a primary workflow reachable from the UI.
- Disable or explain actions unavailable to the current role.
- Preserve user input after recoverable errors.
- Confirm destructive actions and communicate outcomes near the initiating control.
- Keep technical diagnostics collapsed and secondary.

## Finish

- Support narrow mobile, tablet, and wide desktop layouts without horizontal page overflow.
- Provide visible keyboard focus and semantic labels.
- Respect `prefers-reduced-motion`.
- Supply document title, description, theme color, meaningful image alternatives, and useful empty states.
- Avoid remote dependencies, placeholder prose, broken imagery, and hard-coded API origins.
